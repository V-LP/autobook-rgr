# Правила для агента (РГР)

1. Єдине джерело істини: тека docs/. Інших вимог немає. SRS, spec/, src/ і tests/ оригінального проєкту недоступні, і ти їх не шукаєш.
2. Не змінюй docs/. Не вигадуй вимог.
3. Коли документація мовчить, суперечить собі або неоднозначна:
   a) не питай користувача;
   b) прийми найпростіше рішення, яке не суперечить решті docs;
   c) додай запис у GAP-LOG.md: ID, місце в docs, тип, рішення, обґрунтування.
4. Правила й коди відповіді виводь з docs/api/openapi.yaml, user_guide.md, architecture.md, decisions.md, docs/api/html.
5. Кожна функція має docstring за docs/coding_convention.md.
6. У логах і AuditLog немає PII.
7. Комміти малі, з префіксами test:, feat:, docs:, gate:.
8. Посилання в docs на відсутні файли (SRS, spec/, tests/) ігноруй, але зафіксуй у GAP-LOG.md.
