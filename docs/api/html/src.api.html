Booking creation and cancellation API operations.

src.api.bookings.cancel_booking(id: str, payload: CancelBookingRequest | None = None, user: AuthenticatedUser = Depends(dependency=<function require_user>, use_cache=True, scope=None), session: Session = Depends(dependency=<function get_db_session>, use_cache=True, scope=None), now: datetime = Depends(dependency=<function get_clock>, use_cache=True, scope=None)) → BookingResponse[source]

Cancel an owned, confirmed booking when the notice period is satisfied.

The service enforces the two-hour minimum and optional reason limit. The cancellation reason is not included in application logs.

Параметри:

  • id – Booking UUID in string form.

  • payload – Optional cancellation reason, limited to 255 characters.

  • user – Identity supplied by the bearer-token dependency.

  • session – Request-scoped SQLAlchemy session.

  • now – Current time supplied by get_clock.

Повертає:

The updated booking response, including a reason when one was retained.

Викликає:

ApiProblem – If validation fails (400), the booking is unavailable to the client (404), or cancellation is not allowed (400).

Create a pending booking for the authenticated client.

The service applies booking validation and transaction rules; concurrent active-slot conflicts are reported as HTTP 409.

Параметри:

  • payload – Vehicle, master, services, and timezone-aware start time.

  • user – Identity supplied by the bearer-token dependency.

  • session – Request-scoped SQLAlchemy session.

  • now – Current time supplied by get_clock.

Повертає:

The created booking response.

Викликає:

ApiProblem – For rejected booking input (400) or an occupied slot (409).

Search available intervals for the requested active services and date.

The service enforces the 30-day search horizon and minimum booking notice.

Параметри:

  • service_ids – One or more service UUIDs.

  • slot_date – Date query value in canonical YYYY-MM-DD form.

  • user – Authenticated identity required by the endpoint.

  • session – Request-scoped SQLAlchemy session.

  • now – Current time supplied by get_clock.

Повертає:

Available intervals with master identifiers and names.

Викликає:

ApiProblem – If query validation or slot-search rules reject the request.
