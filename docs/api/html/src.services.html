cancel_booking(session: Session, user_id: UUID, booking_id: str, now: datetime, reason: str | None = None) → Booking[source]

Cancel an owned, confirmed booking at least two hours before start.

A blank or whitespace-only reason is treated as absent; non-empty values are limited to 255 characters. The reason is stored for the booking and audit history but is never logged as text; only its presence and length are logged.

Параметри:

  • session – SQLAlchemy session for the cancellation transaction.

  • user_id – Authenticated client’s UUID.

  • booking_id – Booking UUID in string form.

  • now – Current time provided by get_clock.

  • reason – Optional cancellation reason.

Повертає:

The updated booking with CANCELLED_BY_CLIENT status.

Викликає:

  • BookingRejected – If a provided reason exceeds 255 characters.

  • BookingNotFound – If the booking is invalid, missing, or not owned by the client.

  • BookingCancellationNotAllowed – If the booking is not CONFIRMED.

  • LateCancellationDenied – If fewer than two hours remain.

  • SQLAlchemyError – If the transaction fails; database errors are logged and re-raised.

create_booking(session: Session, user_id: UUID, payload: dict[str, Any], now: datetime) → Booking[source]

Create a pending booking with service snapshots and an audit row.

The input start must be timezone-aware and aligned to the configured slot grid. The injected now value is used for availability checks. Database changes are committed together; the partial unique index idx_no_double_booking is translated to BookingConflict.

Параметри:

  • session – SQLAlchemy session for the booking transaction.

  • user_id – Authenticated client’s UUID.

  • payload – Mapping containing vehicle, master, service IDs, and start time.

  • now – Current time provided by get_clock.

Повертає:

The newly persisted booking in PENDING status.

Викликає:

  • BookingRejected – If the payload, vehicle ownership, services, time, or slot availability is invalid.

  • BookingConflict – If the requested interval conflicts with another active booking or the partial unique index.

  • SQLAlchemyError – For other database failures; these are logged and re-raised.

Candidate starts advance on the configured slot grid in Europe/Kyiv time. Intervals must fit within a shift, avoid its break and active bookings, and start at least the configured minimum notice after now.

  • duration_minutes – Combined service duration.

  • slot_date – Local calendar date of the shifts.

  • now – Current time supplied by the caller’s clock.

Повертає:

Available slots sorted by start time and then master UUID.

Anonymize a client while retaining booking and audit history.

The user row is locked and all profile, vehicle, and cancellation-reason updates occur in one transaction. Raw cancellation reasons are replaced in retained history; they are not logged.

Параметри:

  • session – Session that owns the anonymization transaction.

  • user_id – Authenticated user’s UUID.

  • role – Authenticated role; only CLIENT may use this operation.

Повертає:

The updated user row.

Викликає:

  • AnonymizationForbidden – If the role is not CLIENT.

  • LookupError – If the authenticated user row does not exist.

  • SQLAlchemyError – If the transaction fails; the failure is logged and re-raised.
