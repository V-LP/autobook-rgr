src.repositories

Рівень доступу до даних на основі SQLAlchemy. Репозиторії працюють із переданою сесією; межами транзакцій керують відповідні операції сервісів.

Repositories encapsulating database access for persisted AutoBook entities.

Audit persistence boundary; writing status-change records is not implemented.

class src.repositories.audit_repository.AuditRepository[source]

Placeholder repository for immutable, PII-free audit entries.

The current method is intentionally a no-op; persistence is not implemented.

lock_for_master_date(master_id: UUID, shift_date: date) → list[ScheduleShift][source]

Lock the master’s shift rows for a date using SELECT FOR UPDATE.

The caller must execute this query inside the transaction that creates a booking; the lock is held until that transaction ends.

Параметри:

  • master_id – Master whose schedule rows are locked.

  • shift_date – Local calendar date of the requested shift.

Повертає:

The matching shift rows, which may be empty.

Викликає:

SQLAlchemyError – If the query or row lock fails.
